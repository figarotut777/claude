## 📋 Описание

BizCalc - это нативное macOS приложение-калькулятор, специально разработанное для владельцев бизнеса и менеджеров. Помимо стандартных арифметических операций, включает специализированные функции для быстрого расчета маржинальности, наценок, налогов и скидок.

## ✨ Основные возможности

### Бизнес-функции
- **MARGIN** - Расчет цены продажи на основе себестоимости и желаемой маржи
- **MARKUP** - Расчет цены на основе наценки на себестоимость
- **TAX+** - Добавление налога к сумме
- **TAX−** - Выделение суммы без налога
- **DISCOUNT** - Быстрый расчет цены со скидкой

### Базовые функции
- Стандартные арифметические операции (+, −, ×, ÷)
- Форматирование чисел с разделителями тысяч (1 000 000)
- Поддержка отрицательных чисел
- Процентные расчеты
- Защита от деления на ноль

### История вычислений
- "Бумажная лента" со всеми расчетами
- Возможность вернуть результат из истории
- Копирование истории в буфер обмена
- Очистка истории

### UX
- Нативный macOS дизайн с эффектом стекла (glassmorphism)
- Поддержка Dark/Light режимов
- Полная поддержка клавиатуры (NumPad, горячие клавиши)
- Полупрозрачный интерфейс

## 🧮 Формулы и примеры

### ⚠️ Важно: Маржа ≠ Наценка

Это разные показатели! Многие путают их, но математика отличается:

#### MARGIN (Маржа)
**Формула:** `Price = Cost / (1 - Margin/100)`

**Пример:** Себестоимость 100₽, маржа 20%
```
100 → MARGIN → 20 → = → 125₽
```
**Почему 125₽?** Потому что маржа считается от цены продажи:
- Маржа = (Цена − Себестоимость) / Цена
- 20% = (125 − 100) / 125 = 25 / 125 = 0.2 ✓

#### MARKUP (Наценка)
**Формула:** `Price = Cost * (1 + Markup/100)`

**Пример:** Себестоимость 100₽, наценка 20%
```
100 → MARKUP → 20 → = → 120₽
```
**Почему 120₽?** Потому что наценка считается от себестоимости:
- Наценка = (Цена − Себестоимость) / Себестоимость
- 20% = (120 − 100) / 100 = 20 / 100 = 0.2 ✓

#### TAX+ (Добавить налог)
**Формула:** `Value * (1 + TaxRate/100)`

**Пример:** Сумма 1000₽, НДС 20%
```
1000 → TAX+ → 20 → = → 1200₽
```

#### TAX− (Выделить налог)
**Формула:** `Value / (1 + TaxRate/100)`

**Пример:** Сумма с НДС 1200₽, НДС 20%
```
1200 → TAX− → 20 → = → 1000₽
```

#### DISCOUNT (Скидка)
**Формула:** `FinalPrice = Price * (1 - Discount/100)`

**Пример:** Цена 500₽, скидка 15%
```
500 → DISC → 15 → = → 425₽
```

## 🏗️ Архитектура проекта

```
BizCalc/
├── BizCalc/
│   ├── App/
│   │   └── BizCalcApp.swift          # Точка входа приложения
│   ├── Models/
│   │   ├── CalculatorEngine.swift    # Бизнес-логика калькулятора
│   │   └── HistoryItem.swift         # Модель элемента истории
│   ├── ViewModels/
│   │   └── CalculatorViewModel.swift # ViewModel (MVVM)
│   └── Views/
│       ├── ContentView.swift         # Главный экран
│       ├── CalculatorButtonsView.swift # Кнопки калькулятора
│       └── HistoryView.swift         # Панель истории
└── README.md
```

**Паттерн:** MVVM (Model-View-ViewModel)
- **Models** - Чистая бизнес-логика без зависимостей от UI
- **ViewModels** - Связь между Models и Views
- **Views** - SwiftUI компоненты

## 🚀 Установка и запуск

### Требования
- macOS 13 Ventura или новее
- Xcode 15+ с поддержкой Swift 5.9+

### Способ 1: Создание Xcode проекта вручную

1. Откройте Xcode
2. File → New → Project
3. Выберите **macOS → App**
4. Настройки проекта:
   - Product Name: `BizCalc`
   - Interface: `SwiftUI`
   - Language: `Swift`
   - Minimum Deployment: `macOS 13.0`
5. Скопируйте файлы из структуры выше в соответствующие группы Xcode
6. Запустите проект (⌘R)

### Способ 2: Swift Package Manager (будущая опция)
```bash
# В разработке
swift build
swift run
```
