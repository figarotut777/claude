# Инструкция по тестированию StartUp Evolution (Phase 1)

## Предварительные требования

- macOS 14.0+ (Sonoma)
- Xcode 15.0+
- Swift 5.9+

## Шаг 1: Открыть проект

```bash
cd StartUpEvolution
open Package.swift
```

Xcode автоматически создаст и откроет проект.

## Шаг 2: Проверить сборку

В Xcode:
1. Выберите схему "StartUpEvolution"
2. Нажмите `Cmd + B` для сборки
3. Убедитесь, что сборка прошла без ошибок

## Шаг 3: Запустить приложение

Нажмите `Cmd + R` или кнопку "Run"

## Шаг 4: Тестирование функционала

### 4.1 Основная механика

✅ **Тест 1: Клик по кнопке "CODE"**
- Нажмите кнопку `< CODE />`
- Проверьте, что счетчик Money увеличился на $1
- Проверьте, что счетчик XP увеличился на 1
- Проверьте, что прогресс-бар обновился

✅ **Тест 2: Прогресс-бар**
- Кликайте кнопку несколько раз
- Убедитесь, что прогресс-бар заполняется
- Проверьте, что отображается количество XP до следующего уровня

### 4.2 Смена уровней

✅ **Тест 3: Переход на Small Office (51 XP)**
- Используйте debug кнопку "Add 50 XP" или кликайте вручную
- При достижении 51 XP:
  - Название стадии должно измениться на "Small Office"
  - Фон должен плавно поменять цвет
  - В консоли должно появиться: `🎉 Stage changed to: Small Office`

✅ **Тест 4: Все уровни**
- Протестируйте все 5 уровней:
  1. Garage Startup (0-50 XP) — темно-серый фон
  2. Small Office (51-150 XP) — серый фон
  3. Co-Working Space (151-300 XP) — темно-серый фон
  4. Mid-size Company (301-500 XP) — синий фон
  5. Unicorn Status (501+ XP) — темный фон

### 4.3 Persistence (UserDefaults)

✅ **Тест 5: Сохранение прогресса**
1. Накликайте 100 XP
2. Закройте приложение (Cmd + Q)
3. Откройте приложение снова
4. Проверьте, что деньги и XP сохранились
5. В консоли должно появиться: `📱 Game loaded: $100, 100XP, Small Office`

✅ **Тест 6: Кнопка Reset**
1. Накликайте немного XP
2. Нажмите "Reset Game"
3. Проверьте, что все счетчики обнулились
4. Проверьте, что стадия вернулась к "Garage Startup"
5. В консоли: `🔄 Game reset`

### 4.4 CTA Modal

✅ **Тест 7: Появление CTA**
1. Наберите 501+ XP (используйте debug кнопку несколько раз)
2. Должно появиться модальное окно с поздравлением
3. Проверьте текст: "Ваш стартап достиг статуса Единорога!"
4. Проверьте, что кнопка присутствует

✅ **Тест 8: CTA кнопка**
1. Нажмите "Узнать, как мы можем помочь"
2. Должен открыться браузер с URL (по умолчанию placeholder)
3. Или нажмите "Закрыть" — модальное окно должно исчезнуть

✅ **Тест 9: CTA показывается один раз**
1. Достигните Unicorn Status
2. Закройте модальное окно
3. Перезапустите приложение
4. Модальное окно не должно появиться снова

### 4.5 UI/UX

✅ **Тест 10: Адаптивность**
- Измените размер окна — UI должен корректно отображаться
- Минимальный размер: 600x700

✅ **Тест 11: Анимации**
- Проверьте плавную анимацию смены фона
- Проверьте анимацию прогресс-бара
- На уровне Unicorn кнопка "CODE" должна пульсировать

### 4.6 Debug функции

✅ **Тест 12: Debug кнопки**
- "Add 50 XP" — должна добавить 50 к текущему XP
- "Reset Game" — должна обнулить все счетчики

## Шаг 5: Проверка консоли

В Xcode откройте консоль (View → Debug Area → Activate Console) и проверьте логи:

```
📱 Game loaded: $0, 0XP, Garage Startup
🎉 Stage changed to: Small Office
🎉 Stage changed to: Co-Working Space
...
```

## Troubleshooting

### Ошибка компиляции
- Убедитесь, что используете Xcode 15+ и macOS 14+
- Очистите build folder: Product → Clean Build Folder (Cmd + Shift + K)

### Приложение не запускается
- Проверьте, что выбрана правильная схема "StartUpEvolution"
- Проверьте консоль на наличие ошибок

### UserDefaults не сохраняет данные
- Проверьте права доступа приложения
- Попробуйте полностью удалить и пересобрать приложение
