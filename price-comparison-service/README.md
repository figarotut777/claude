# Price Comparison Service

Сервис для сравнения цен на товары с российских маркетплейсов (Yandex Market, Wildberries, Ozon).

## Описание

Решает проблему, когда один и тот же товар продаётся на разных маркетплейсах по разным ценам. Сервис автоматически находит одинаковые товары и показывает, где купить дешевле.

### Основные возможности

- **Поиск по текстовому запросу**: введите "кожаная сумка Feruni" и получите цены со всех маркетплейсов
- **Поиск по URL товара**: вставьте ссылку на товар с одного маркетплейса, сервис найдёт его на других
- **Умное сопоставление товаров**: использует штрих-коды, бренды, модели и fuzzy matching
- **API-first**: готовый REST API с автоматической документацией

### Поддерживаемые маркетплейсы

- ✅ Yandex Market
- ✅ Wildberries
- ✅ Ozon

Архитектура позволяет легко добавлять новые маркетплейсы.

### Алгоритм сопоставления товаров

Сервис использует многоступенчатый алгоритм для определения одинаковых товаров:

1. **GTIN matching** (confidence: 1.0)
   - Прямое совпадение по штрих-коду/EAN
   - Самый точный метод

2. **Brand + Model matching** (confidence: 0.95)
   - Совпадение по бренду и модели
   - Высокая точность

3. **Fuzzy name matching** (confidence: 0.80-0.90)
   - Использует rapidfuzz для сравнения названий
   - Удаляет стоп-слова ("купить", "скидка" и т.д.)
   - Нормализует текст

4. **Attribute validation** (bonus: +0.1)
   - Проверка ключевых атрибутов (цвет, размер, материал)
   - Увеличивает уверенность при совпадении

## Варианты легализации доступа к данным

### 1. Официальные API

**Плюсы:**
- Легальный доступ
- Структурированные данные
- Поддержка от маркетплейса

**Минусы:**
- Требуется партнёрство
- Ограничения по rate limits
- Не все маркетплейсы предоставляют

**Доступность:**
- Yandex Market: есть Partner API (требует регистрации)
- Ozon: есть Seller API (для продавцов)
- Wildberries: API ограничен (в основном для продавцов)

### 2. Парсинг с соблюдением правил

**Рекомендации:**
- Читать и соблюдать robots.txt
- Использовать User-Agent браузера
- Уважать rate limits (не более 1 запроса в секунду)
- Кешировать результаты
- Не создавать чрезмерную нагрузку

**Юридические аспекты:**
- В РФ парсинг публичных данных легален
- Важно не нарушать авторские права
- Не использовать данные для конкурентной борьбы с маркетплейсом

### 3. Партнёрские программы

Рассмотреть возможность вступления в партнёрские программы:
- Получить официальный доступ к API
- Монетизировать через реферальные ссылки
