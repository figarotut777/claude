# Развёртывание WB Analytics для работы с реальными данными

## Проблема с Claude Code

Claude Code использует прокси-сервер, который **блокирует доступ к Wildberries API** (домен `statistics-api.wildberries.ru` не в whitelist). Поэтому для получения реальных данных нужно запустить приложение вне Claude Code.

## Способ 1: Локальный запуск (рекомендуется)

### Шаг 1: Клонируйте репозиторий на вашу машину

```bash
git clone <ваш-репозиторий>
cd wb_analytics
```

### Шаг 2: Установите зависимости

```bash
python3 -m pip install -r requirements.txt
```

### Шаг 3: Настройте .env файл

Убедитесь, что в файле `.env` указан ваш реальный API ключ Wildberries:

```bash
WB_API_KEY=ваш_реальный_ключ
DB_PATH=data/wb_analytics.db
PORT=8080
```

### Шаг 4: Запустите первичную настройку

```bash
python scripts/setup.py
```

Это:
- Создаст базу данных
- Подключится к WB API (без прокси!)
- Загрузит данные за последние 365 дней
- Синхронизирует продажи, заказы, остатки и финансовые отчёты

### Шаг 5: Запустите веб-сервер

```bash
PORT=8080 python scripts/start_server.py
```

Откройте в браузере: `http://localhost:8080`

## Способ 2: Развёртывание на сервере

### На VPS/облачном сервере:

```bash
# 1. Клонируйте репозиторий
git clone <ваш-репозиторий>
cd wb_analytics

# 2. Установите зависимости
pip3 install -r requirements.txt

# 3. Настройте .env с вашим WB API ключом

# 4. Запустите setup
python3 scripts/setup.py

# 5. Запустите сервер (в фоне)
nohup python3 scripts/start_server.py > logs/server.log 2>&1 &
```

### Настройка автообновления (cron)

Для автоматической синхронизации данных каждый час:

```bash
bash scripts/setup_cron.sh
```

Теперь API интеграция полностью совместима с актуальной версией WB API 2025.

## Проверка работы API

После запуска `setup.py` в логах должно быть:

```
✓ Подключение к API успешно
Получено X записей о продажах
Получено Y записей о заказах
Получено Z записей об остатках
Получено N записей детального отчета
```

Если вы видите 0 записей - возможно у вас действительно нет продаж за указанный период.

## Поддержка

Если после локального запуска данные всё равно не загружаются:
1. Проверьте API ключ в личном кабинете WB
2. Убедитесь, что ключ имеет права на "Статистика"
3. Проверьте, есть ли у вас реальные продажи за последние дни

---

**Важно**: Все исправления API уже в коде, осталось только запустить вне Claude Code!
